# Včelárstvo Trizuliak

Viacstránkový interaktívny dizajnový návrh e-shopu na prezentáciu klientovi.

## Živá ukážka

https://matejsmutny1-droid.github.io/vcelarstvo-trizuliak-navrh/

## Rozsah

36 samostatných HTML stránok: úvod, katalóg, tri kategórie, 15 produktov, vlastná výroba, príbeh, poradňa a tri články, kontakt, platba a doprava, obchodné podmienky, ochrana súkromia, veľkoobchod, vyhľadávanie, košík, pokladňa, ukážka potvrdenia a vysvetlenie návrhu.

Obsahové odkazy zostávajú v novom webe. Telefonické a emailové odkazy a navigácia do predajne používajú príslušnú externú aplikáciu.

Košík sa ukladá len v prehliadači. Kontaktný formulár, veľkoobchodný dopyt aj pokladňa fungujú ako ukážka bez odoslania údajov, skutočnej objednávky alebo platby. Ceny a dostupnosť sú statickou snímkou ponuky. Varianty slúžia na ukážku konfigurátora a finálny cenník treba doplniť.

Právne stránky sú návrhom členenia a pred ostrým spustením vyžadujú finálne znenie schválené prevádzkovateľom. Články obsahujú nový orientačný redakčný text pre návrh.

## Podklady a AI

Úvodný obrázok hero.jpg je ilustračná AI fotografia. Je viditeľne označený priamo na úvodnej stránke a opísaný na stránke O tejto ukážke. Nie je fotografiou skutočnej prevádzky alebo pracovníka klienta.

Logo, produktové fotografie a fotografia predajne pochádzajú z verejného webu Včelárstva Trizuliak a slúžia pre tento klientsky návrh. Nie sú poskytované ako voľne licencované fotografie. Podrobnosti a prompt úvodného obrázka sú v ASSETS.md. Licencie fontov sú vo FONT-LICENSES.txt.

## Spustenie

Statický web bez závislostí a buildu. GitHub Pages: vetva main, priečinok / (root).

Lokálne: python3 -m http.server 4173.

Katalógové údaje sú v catalog-data.js, spoločné správanie v app.js a štýly v styles.css. Všetky stránky majú noindex. Návrh neobsahuje analytické ani reklamné značky.
